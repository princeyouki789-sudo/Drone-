Project Description:
Our project Is a voice controlled drone. It has many voice commands we implemented to give fine controls to the drone. After accomplishing this we felt our project wasn't great enough so we also added facial recognition to the drones camera feed. The biggest and most important thing we learned from this project is how to teach ourself on new coding libraries. Studying the drone's, and voice model's library was a huge experience boost on how to done for different devices. It was very helpful.

Project Experience:
Our creative director Chelsea came up with the great idea of have our club issued drone have the ability to be controlled using voice commands. Since our team is made up of people with little to no coding experience, we decided the project was the right amount of difficulty for us. There wasn't many major difficulties we had to face. I was mostly code breaks which were just errors on out part and once we wrote the code right, everything just sort of worked.
